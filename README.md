
 # Financial Consulting Website

 Front-end project for a financial consulting platform built with React, TypeScript, Vite, React Router, Tailwind CSS, Radix UI, and Vitest.

 ## Assignment Support

 The project includes dedicated documentation for the SDI assignment:

 - `docs/assignment-0-bronze-checklist.md` for the required bronze prototype screens
 - `docs/assignment-1-stack-benchmark.md` for the technology stack benchmark and justification
 - `docs/assignment-1-requirements-checklist.md` for the implementation checklist mapped to the codebase
 - `docs/assignment-2-stack-benchmark.md` for the back-end stack benchmark and justification
 - `docs/assignment-2-requirements-checklist.md` for the REST API bronze checklist

 ## Running the front end

 - `npm install`
 - `npm run dev`

 ## Running the back end

 - `npm run dev:server`
 - `npm run start:server`

 The REST API runs on `http://localhost:3001` by default.

 ## Testing

 - `npm test -- --run`
 - `npm run test:coverage`
